            Language model off
            
          
            Only one feature uses this today: asking a model to
             propose the rules a form declares about itself, on the Schema
             step. Nothing else here needs it, and no generated record is ever
             sent - what goes out is field names, labels and option lists.
            

          
            
          
              

          
              

          
              A key typed here is held in this server's memory and
             written nowhere - not to the database, not to the library, not to
             a log - so it is forgotten when the server restarts. For one that
             lasts, export ANTHROPIC_API_KEY or
             OPENAI_API_KEY before starting it.
              

          
              
            
            
            
            
            
          
              
        
              

        
        
              
          
              API tokens 0
              
          
              A token lets another application ask your trained
             models what to put in a form, over the
             /v1 service. It reads your library and nobody
             else's, and it is not a password: revoking one changes nothing
             about how you sign in.
